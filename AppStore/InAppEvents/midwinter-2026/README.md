# アプリ内イベント「冬至から大寒の空玉」（2026年12月〜2027年1月）

状態: 案。App Store Connect には未作成・未提出。アプリの更新はいらない（今あるアプリの内容だけを使う）。

## 中身（アプリに実際にあるもの）

- 冬至（2026-12-22）・小寒（2027-01-05）・大寒（2027-01-20）に記録した空玉は、詳細に節気の名前とひとことが出て、記録したときにお祝い表示が出る。
- 満月の夜（アプリの判定は21時基準で 2026-12-23・12-24、2027-01-22）に夜の空玉を記録すると、玉の中にまるい月が映る。
- 日付は `SolarTerm.on`・`MoonPhase.on` で計算した（東京）。クリスマスのイベント（12/1〜12/25）と期間が重なるが、App Store では同時に複数のイベントを出せる。

## ノミネートの文案（新しいコンテンツ、公開日 2026-12-22〜2027-01-22、iPhone）

- 名前: 空玉 冬至から大寒の空玉（2026年12月〜2027年1月）
- 説明:

  空玉は、毎日の天気を小さなガラス玉にして集めていく天気アプリです。天気や気温、時間帯によって玉の色や模様が変わり、ひと月続けるとカレンダーに玉がずらっと並びます。

  空玉は二十四節気と月の満ち欠けを計算していて、節気の日に記録した玉には、その節気の名前とひとことが添えられます。満月の夜に記録した玉には、まるい月が映ります。

  12月22日の冬至から1月20日の大寒までは、一年でいちばん寒く、夜が長い時期です。冬至、小寒、大寒の3つの節気と、2回の満月が続きます。年末年始に毎日の空を集めながら、冬の暦をたどれるようにしたくて、この期間をアプリ内イベントにしました。

  広告、アカウント登録、トラッキングはありません。日本語と英語に対応しています。

- 役立つ情報: ハロウィン・クリスマスのノミネートと同じ文面。
