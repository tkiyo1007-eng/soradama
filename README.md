# そらだま(空玉)☀️🌙

世界最高峰のデザイン品質を目指した、SwiftUI 製の天気予報 iOS アプリ。
アイコンの「空を閉じ込めたガラス玉」がそのまま名前になっています。

> 内部のプロジェクト名・ターゲット名は `AuroraWeather` のままです(表示名は「そらだま」)。バンドル ID は公開用に `com.tkiyo1007.soradama` を設定済み。公開手順は **AppStore公開ガイド.md** を参照してください。

## デザインのこだわり

- **生きた空** — 天候(晴れ/くもり/雨/雪/雷雨/霧)× 昼夜で変化するスカイグラデーション。雨粒・雪・光の帯(リボン)を `Canvas + TimelineView` によるステートレスな 60fps 描画で重ねる。
  - ※ App Review (Guideline 5.2.5) 対応で、太陽/月/星空/雲塊/稲光などApple純正「天気」を想起させる写実表現は v1.0 審査中に撤去済み。詳細は AppStore公開ガイド.md の教訓メモを参照
- **そらだまカード** — 空色〜藍色のグラデーション縁取り + 差し色シャドウで統一したカードシステム(純正風の白フチ磨りガラスは審査対応で廃止)。
- **情報の美しさ**
  - 10日間予報: 週全体レンジに対する各日の気温バー(温度で色が変わるグラデーション、今日は現在気温ドット付き)
  - Swift Charts による24時間気温カーブ(サンセットカラーのライン + エリアグラデーション)
  - 風向: 矢印バッジ + 16方位表示 / 日の出〜日の入り・UV指数はリングゲージで統一
  - 湿度バー(視程併記)・気圧/体感温度のコメント付きカード・傘指数(独自項目)
- **マイクロインタラクション** — スクロールで大きな気温表示が縮んでコンパクトヘッダーへ遷移、`contentTransition(.numericText())`、ハプティクス、Pull-to-Refresh。

## 機能

- **世界の空から始められる初回設定** — 現在地の利用か、都市を検索して「マイスカイ」にするかを選択。位置情報を許可しなくても任意の都市で利用可能
- **複数都市のスワイプページング** — 現在地 + マイシティを左右スワイプで切り替え(ページドット付き)
- **雨雲レーダー** — 気象庁 高解像度降水ナウキャスト + MapKit。過去1時間の実況と60分先の予測をスライダー/自動再生で確認。日本周辺の地点だけに表示し、海外では利用できない機能を見せない
- **オフラインキャッシュ** — 取得地点を照合した6時間以内の天気を保存。圏外時は「保存済み」と取得時刻を明示し、別の現在地の古い予報を誤表示しない
- 都市検索(日本語対応・デバウンス付き)とマイシティ保存(スワイプ削除)
- **地域に合う表示** — 端末の地域に合わせた摂氏/華氏の初期値、週の開始曜日、日付・時刻書式に対応。南半球では空玉の季節表現を半年分入れ替える
- 現在・24時間・10日間の予報、詳細メトリクス7種
- **気象庁(JMA)予報モデル対応** — 日本近域では Open-Meteo の `models=jma_seamless` を使用し予報精度を向上。JMA が提供しない UV 指数・降水確率・視程はグローバルモデルへの並行リクエストで補完(`Shared/WeatherService.swift`)
- タイムゾーン対応(検索した都市の現地時刻で表示)
- **ホーム画面ウィジェット(WidgetKit)** — 小: 現在の天気と最高/最低、中: +2時間おきの予報。背景はアプリと同じ天候グラデーション。30分ごとに自動更新
- **ロック画面ウィジェット** — 円形・長方形・インラインの3種
- **雨の降り始め通知** — 12時間以内に降水確率50%以上の予報があれば、降り出し約30分前にローカル通知(検索シートのトグルでON/OFF)
- **Apple Watch アプリ** — 現在の天気・6時間分の毎時・5日間予報。`WatchConnectivity`でiPhoneのマイスカイ・単位・最新の天気を同期し、保存済み天気も明示
- **英語対応(v1.6.0〜)** — 日本語をソース言語とし、String Catalog(`Localizable.xcstrings`)で英語を提供。時刻・日付・曜日は書式テンプレートで組み立てるため、英語圏では "3 PM" のように現地の慣習で表示される。雨雲レーダーは気象庁データのため日本周辺だけに表示する
- **空玉バックアップ** — JSONへの書き出しと、追加/置換のプレビュー付き復元。容量・件数・数値・文字列を検証し、競合や保存失敗時は安全に中断/ロールバック
- **投げ銭(Tip Jar)** — 消耗型のアプリ内課金を3段階。機能はいっさいアンロックされず、広告も元から無い。購入回数だけをローカルに記録し、お礼の言い方を少し変える(`AuroraWeather/Services/TipJar.swift`)
- **アクセシビリティ** — 毎時/10日間/風向コンパスなどにVoiceOver読み上げラベル、「視差効果を減らす」設定でパーティクルを静止画に切り替え
- **プライバシー優先** — アカウント不要、広告・行動トラッキングなし。位置情報は天気と地点名の取得にだけ使い、開発者のサーバーでは収集・保存しない。4ターゲットにPrivacy manifestを同梱

## アーキテクチャ

```
soradama/
├── AuroraWeather/          アプリ本体ターゲット
│   ├── App/                エントリポイント
│   ├── Services/           Geocoding / Cache / Watch sync / Backup / Background refresh
│   ├── ViewModels/         WeatherViewModel(@Observable, MVVM)
│   ├── Views/
│   │   ├── Sky/            背景グラデーション・パーティクル演出
│   │   ├── Components/     GlassCard
│   │   ├── Sections/       ヘッダー / 毎時 / チャート / 10日間 / 詳細グリッド
│   │   └── Search/         都市検索シート
│   └── Utilities/          ハプティクス
├── Shared/                 全ターゲット共有: モデル / API / 6時間キャッシュ / Watch同期payload / バックアップ
├── AuroraWeatherWidget/    ホーム画面ウィジェット(WidgetKit)
├── SoradamaWatch/          Apple Watch アプリ(watchOS 10+)
└── SoradamaWatchWidget/    Watchコンプリケーション(WidgetKit)
```

- **API**: [Open-Meteo](https://open-meteo.com/)(無料・APIキー不要)
- **要件**: Xcode 16+ / iOS 17.0+
- **依存パッケージ**: なし(すべて標準フレームワーク)

## 実行方法

1. `git clone https://github.com/tkiyo1007-eng/soradama.git` してから `AuroraWeather.xcodeproj` を Xcode で開く
2. Signing & Capabilities で自分のチームを選択
3. シミュレータまたは実機で ⌘R

初回起動時は、「現在地を使う」と「都市を選ぶ」からマイスカイを決めます。位置情報を使わない場合も、都市検索からそのまま利用できます。温度単位は端末の地域に合わせて初期選択され、後から設定で変更できます。

### ウィジェットについて

ホーム画面長押し → 「+」→ そらだま で追加できます。アプリ本体・ウィジェット・Watch間で地点と単位を共有するには、4つの配布ターゲットで App Group `group.com.tkiyo1007.soradama` を一致させます。iPhoneとWatchの直接同期にはあわせてWatchConnectivityを使い、開発者のサーバーは介しません。
