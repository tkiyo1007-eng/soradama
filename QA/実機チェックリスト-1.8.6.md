# 実機チェックリスト（1.8.6 の提出前）

シミュレータでは確かめられないことを、実機で15〜20分で確かめるための表です。
結果の欄に ○ / × / 気づいたことを書いて、Claude に渡してください。× の項目から直します。

**先に**: 設定 →「空玉をバックアップ」で JSON を保存しておく（A の項目でアプリを入れ直すと空玉が消えるため）。
A は、今使っている iPhone で入れ直したくなければ、別の端末か「あとで」でかまいません。

| # | 確かめること | こうなれば ○ | 結果 |
|---|---|---|---|
| **A. 初回起動**（アプリを入れ直す） | | | |
| A1 | 初回案内の「つぎへ」を2回押す | 毎回すぐ次のページへ進む（進まないことがあれば、そのときの文字サイズと回数） | |
| A2 | 設定 → アクセシビリティ → 画面表示とテキストサイズ → さらに大きな文字 を最大にして初回案内を見る | 文字が切れず、「つぎへ」「現在地を使う」「都市を選ぶ」が押せる | |
| A3 | 3ページ目「現在地を使う」→ 許可ダイアログで「許可しない」 | 止まらずに都市選択へ進める | |
| A4 | 「都市を選ぶ」→「上越」と入力 | 「上越市 新潟県 / 日本」が出て、選ぶと天気画面になる | |
| A5 | 都市選択を開いて「閉じる」 | 初回案内に戻り、地点は確定されない | |
| **B. 天気画面** | | | |
| B1 | 天気画面を上から下まで見る | 現在の天気、時間ごと、傘指数、洗濯指数、体感、UV、風、湿度、気圧、10日間、日の出が出る | |
| B2 | UV のカード | 数値と「低い」などの段階。取れていない日は「—」と「データなし」（0 ではない） | |
| B3 | 機内モードにして、画面を下に引く | 「保存済みの天気」の帯と取得時刻が出る。機内モードを戻して「再試行」で更新される | |
| B4 | 「今日の空玉」カードをタップ | 玉の詳細が開き、「共有」で画像ができる。画像の下に「App Storeで「空玉」と検索 · #空玉」 | |
| B5 | 10月中の見た目 | 背景に月とこうもり、今日の玉にジャックオランタン、カードに「10月31日まで」 | |
| B6 | 設定 → アクセシビリティ → 動作 → 視差効果を減らす を ON | こうもりが止まった状態で表示される（消えてもよい） | |
| **C. コレクション** | | | |
| C1 | 左上の玉をタップ | カレンダーに今日の玉がある。玉が少ないと「空玉はいつ残る？」の案内が開いている | |
| C2 | 「この月をふりかえる」 | ひと月のまとめが開き、共有できる | |
| **D. VoiceOver**（設定 → アクセシビリティ → VoiceOver を ON。3本指で上下に移動、右スワイプで次へ） | | | |
| D1 | 天気画面を右スワイプで読み進める | 「onboarding.next」のような英数字の名前や、意味の分からない読み上げが無い | |
| D2 | 「今日の空玉」カード | 「今日の空玉、晴れ、夜の空、…、ボタン」のように読み、ヒントで「共有もできます」と言う | |
| D3 | UV・風・湿度のカード | 「UV指数、3、中程度」「風、北、3メートル毎秒」のように読む | |
| D4 | コレクションの玉 | 「2026年10月16日の空玉、秋の夜、晴れ」のように読む | |
| **E. ウィジェットと Watch** | | | |
| E1 | ホーム画面に「今日の空玉」（小）と「現在の天気」を追加 | 玉と連続日数、現在の天気が出る。しばらくしても更新が止まらない | |
| E2 | ロック画面にウィジェットを追加 | 表示される | |
| E3 | Apple Watch の空玉を開く | iPhone と同じ地点と単位。コンプリケーション（円形・長方形・1行）が出る | |
| E4 | iPhone の設定で単位を華氏に変える | iPhone の数値が変わり、Watch も少し待つと変わる | |
| **F. 通知** | | | |
| F1 | 設定で3つの通知を ON | 通知の許可が求められ、ON のまま残る | |
| F2 | 翌朝7時 | 傘予報の通知が届く（翌日に記入） | |
| **G. バックアップ** | | | |
| G1 | 設定 →「空玉をバックアップ」→ ファイルに保存 →「バックアップから復元」で同じファイル | 「追加 0個、更新 N個」のように出て、空玉が減らない | |

気づいたことがあれば、そのときの画面写真（特に × のとき）も添えてください。
